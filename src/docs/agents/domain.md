# 领域文档

本文件规定工程技能探索代码库时如何读取和使用领域文档。

## 探索前读取

- **`src/GLOSSARY.md`**：全仓库共享的领域术语表。
- **`src/docs/adr/`**：读取与当前工作领域相关的架构决策记录（ADR）。

文件不存在时静默继续，无需报告缺失或提前建议创建。术语或决策确定后，由 `/domain-modeling` 技能按需创建。

## 文件布局

本仓库采用以 `src` 为根的单上下文布局：

```text
/
├── src/
│   ├── GLOSSARY.md
│   └── docs/adr/
└── ...
```

## 使用术语表中的词汇

在任务标题、重构提案、假设或测试名称等输出中提及领域概念时，使用 `src/GLOSSARY.md` 定义的术语，避免使用术语表明确排除的同义词。

所需概念尚未收录时，先确认项目是否使用该概念；如果确有缺口，记录下来供 `/domain-modeling` 技能处理。

## 明确指出 ADR 冲突

输出与已有 ADR 冲突时，明确指出冲突及重新讨论的理由：
