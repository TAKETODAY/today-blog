# 分诊标签

工程技能使用五个标准分诊角色。本文件将这些角色映射到本仓库 GitHub Issues 中实际使用的标签名称。

| 技能中的标准角色 | 跟踪器中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可交由 Agent 自主实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提及某个分诊角色时，使用表中对应的标签名称。
